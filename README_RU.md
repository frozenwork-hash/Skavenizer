# Скавенизатор

Утилита на Python для художественного преобразования текста: дублирует
отдельные слова через дефис, присоединяет синонимы и добавляет
языкозависимый суффикс «тварь/thing» к одушевлённым существительным.
Рассчитана на пародийные и лингвистические эксперименты с русским и
английским текстом.

## Обзор

Скавенизатор читает текст из файла (`.txt`, `.docx`, `.doc`, `.pdf`),
из аргумента командной строки или из стандартного ввода и возвращает
преобразованную версию. К каждому слову применяется одна из четырёх
взвешенно-случайных операций:

- **duplicate** — слово дублируется через дефис (`да-да`, `yes-yes`);
- **synonym** — к слову добавляется синоним через дефис (`хорошо-впору`);
- **tvari** — слово сводится к корню и получает суффикс «тварь» /
  «thing» (`чело-тварь`, `dog-thing`);
- **keep** — слово остаётся без изменений.

Операция «tvari» применяется только к **одушевлённым** существительным,
что определяется морфологическим анализом (для русского) или классами
WordNet (для английского). Число согласуется: единственное число
получает суффикс единственного числа, множественное — множественного.

## Как это работает

Конвейер состоит из шести этапов:

1. **Получение ввода.** Источником может быть путь к файлу, «сырая»
   строка или `-` (стандартный ввод). Тип файла определяется по
   расширению.
2. **Токенизация.** Текст разбивается регулярным выражением на токены
   с сохранением пробелов и знаков препинания.
3. **Поэтапное преобразование.** Каждый буквенный токен проходит через
   взвешенный случайный выбор.
4. **Определение языка.** Слово считается русским, если содержит хотя бы
   одну кириллическую букву; в противном случае — английским.
5. **Проверка одушевлённости.** Русская одушевлённость определяется
   через `pymorphy3` (граммема `anim`); английская — через WordNet
   (`noun.animal`, `noun.person`).
6. **Реконструкция и вывод.** Токены склеиваются и записываются в файл
   и (если не подавлено) в стандартный вывод.

## Возможности

- **Множество форматов ввода.** `.txt`, `.docx`, `.doc`, `.pdf`,
  «сырой» текст, stdin.
- **Устойчивость к кодировкам.** `.txt` декодируется с автоматическим
  fallback: UTF-8 → CP1251 → Latin-1.
- **Двуязычность.** Русский и английский, независимо для каждого слова.
- **Согласование числа.** `человек → человеко-тварь`,
  `люди → человеко-твари`; `dog → dog-thing`, `dogs → dog-things`.
- **Сохранение регистра.** `Собака → Собако-тварь`,
  `СОБАКА → СОБАКО-ТВАРЬ`.
- **Опциональные морфологические движки.** Pymystem3 (русская
  лемматизация), inflect (английское число), pymorphy3 (русская
  морфология), RuWordNet и NLTK WordNet (синонимы). Каждый движок
  загружается лениво и корректно деградирует при отсутствии.
- **CLI** с настраиваемыми весами, seed, путём вывода и режимами
  quiet/preview.
- **Честная диагностика.** Активные движки сообщаются в `stderr` до
  начала обработки.

## Установка

### Минимальная (только stdlib)

Скрипт работает без сторонних пакетов, но с урезанной
функциональностью:

```bash
git clone https://github.com/<ваш-логин>/skavenizer.git
cd skavenizer
python skavenizer.py "Человек идёт домой"
```

Рекомендуемая

Установите все опциональные движки для полной функциональности:

```bash
pip install python-docx pypdf textract ruwordnet nltk pymorphy3 pymystem3 inflect
python -c "import nltk; nltk.download('wordnet')"
ruwordnet download
```

На Windows textract дополнительно требует antiword и libmagic для
поддержки .doc. При их отсутствии скрипт выдаст понятную ошибку.

Версия Python

Python 3.9 или новее. Импорт from __future__ import annotations
обеспечивает работу синтаксиса PEP 604 (объединения через |) на
версии 3.9.

Использование

Базовое

```bash
python skavenizer.py input.docx
python skavenizer.py "Человек идёт домой. The dog runs fast."
echo "some text" | python skavenizer.py -
```

Опции

- `source` — Путь к файлу, «сырой» текст или `-` для stdin.
- `-o, --output PATH` — Путь вывода. По умолчанию: `<stem>_skavenized.txt` для файлов, иначе `skavenized_output.txt`.
- `--seed INT` — Seed для RNG (для воспроизводимости).
- `--weights DUP SYN TVA KEEP` — Четыре неотрицательных веса (по умолчанию `0.15 0.15 0.15 0.55`).
- `-q, --quiet` — Подавить stdout и диагностику. Ошибки по-прежнему идут в stderr.
- `--preview N` — Печатать только первые N символов.

Примеры

Воспроизводимый запуск с фиксированным seed:

```bash
python skavenizer.py input.txt --seed 42 -o out.txt
```

Только «tvari» (отключить дублирование, синонимы и no-op):

```bash
python skavenizer.py input.txt --weights 0 0 1 0
```

Показать первые 300 символов:

```bash
python skavenizer.py input.pdf --preview 300
```

Пакетный режим (без stdout):

```bash
python skavenizer.py input.txt -q
```

Правила преобразования

Duplicate

Слово повторяется через дефис. Пунктуация и пробелы сохраняются.

```
да    → да-да
yes   → yes-yes
```

Synonym

Синоним добавляется через дефис. Синоним берётся из RuWordNet
(русский) или NLTK WordNet (английский). Если синоним не найден,
слово остаётся без изменений.

```
хорошо → хорошо-впору
fast   → fast-quick
```

Tvari (tvarizация)

Применяется только к одушевлённым существительным.

Русский. Слово сводится к корню (через pymystem3-лемматизацию при
наличии, иначе — эвристикой по первым 4 буквам), усекается по конечным
гласным и получает соединительное -о- перед суффиксом тварь
(единственное число) или твари (множественное). Если корень
оканчивается на гласную, соединительное о не добавляется.

```
человек  (ед.) → человеко-тварь
люди     (мн.) → человеко-твари
кошка    (ед.) → кошко-тварь
кошки    (мн.) → кошко-твари
я        (ед.) → я-тварь
```

Английский. Срезается только окончание множественного числа;
корень не усекается. Суффикс — -thing (ед.) или -things (мн.).
Irregular-плюралы (mice, children) и invariant-слова (series,
news, sheep) обрабатываются корректно при установленном inflect.

```
dog   (ед.) → dog-thing
dogs  (мн.) → dog-things
mouse (ед.) → mouse-thing
mice  (мн.) → mouse-things
series      → series-things
```

Keep

Слово остаётся без изменений. Это исход для большинства слов
(вес 0.55).

Опциональные движки

- `pymystem3` — Русская лемматизация для точного корня. Установка: `pip install pymystem3`
- `inflect` — Английские irregular-формы числа. Установка: `pip install inflect`
- `pymorphy3` — Русская одушевлённость и число. Установка: `pip install pymorphy3`
- `ruwordnet` — Русские синонимы. Установка: `pip install ruwordnet`
- `nltk + WordNet` — Английские синонимы и одушевлённость. Установка: `pip install nltk` и `nltk.download('wordnet')`
- `pypdf` — Чтение PDF (fallback на PyPDF2). Установка: `pip install pypdf`
- `python-docx` — Чтение `.docx`. Установка: `pip install python-docx`
- `textract` — Чтение `.doc`. Установка: `pip install textract`

При отсутствии движка скрипт выводит однострочное предупреждение в
stderr (до начала обработки) и переходит на эвристику. Исключение не
возникает, вывод остаётся валидным.

Справочник функций

I/O

- `extract_text(path)` — Диспетчеризация по расширению файла.
- `_read_text_file(path)` — Чтение `.txt` с fallback-кодировками.
- `_decode_bytes(data)` — Декодирование байтов: UTF-8 → CP1251 → Latin-1.

Морфология

- `is_animate_ru(word)` — Русская одушевлённость (`pymorphy3`).
- `is_animate_en(word)` — Английская одушевлённость (WordNet).
- `is_plural_ru(word)` — Русское число (`pymorphy3`).
- `is_plural_en(word)` — Английское число (`inflect`; fallback — эвристика).
- `singular_en(word)` — Единственное число английского слова.
- `lemma_ru(word)` — Русская лемма (`pymystem3`, с кэшем).
- `russian_root(word)` — Корень: `pymystem3` или эвристика.

Преобразования

- `make_beast_ru(word)` — Русская «tvari»-трансформация.
- `make_beast_en(word, plural, sg)` — Английская «thing»-трансформация.
- `apply_case(source, target)` — Применяет регистр `source` к `target`.
- `skavenize_word(word, weights)` — Взвешенное случайное преобразование слова.
- `skavenize_text(text, weights)` — Применяет `skavenize_word` к каждому токену.

CLI

- `parse_args()` — Разбор и валидация аргументов CLI.
- `_default_output_for(source, is_file)` — Выбор пути вывода по умолчанию.
- `_print_diagnostics(quiet)` — Сообщает активные движки в stderr.
- `main()` — Точка входа.

Ограничения

- PDF с кириллицей. Бэкенды `pypdf`/`PyPDF2` часто выдают мусор
  для кириллических PDF. Это ограничение библиотеки, не Скавенизатора.
- `.doc` на Windows. Требует установленных `antiword` и `libmagic`
  в PATH.
- Irregular-корни русского. Без `pymystem3` корень извлекается
  4-буквенной эвристикой и может быть неточен на сложных словах.
- Качество синонимов. RuWordNet и WordNet возвращают первый
  доступный синоним; он не всегда идиоматичен в контексте.
- Смешанные токены. Слово считается русским, если содержит хотя бы
  одну кириллическую букву; токены вида `abcа` (латиница + кириллица)
  уйдут в русскую ветку.
- Irregular-регистр в `apply_case`. Смешанный регистр (`СоБака`)
  нормализуется до `Собак…`.
- Пустой ввод. Завершается с кодом 0 и сообщением `Text is empty.`
  в stderr.
